# UI Tokens — React Native Pomodoro

> Pixel match of the Editorial theme from the web app.

## Colors (Editorial Theme)
All values stored as constants in `lib/tokens.ts`:

| Token | Value | Usage |
|-------|-------|-------|
| bg | `#F2EDE4` | App background (warm ivory) |
| surface | `#EBE4D8` | Card backgrounds |
| surface-hover | `#E3DACC` | Hover/pressed state |
| border | `#D9CFC0` | Dividers, borders |
| ink | `#3D3935` | Primary text (warm dark) |
| ink-muted | `#6B6560` | Secondary text |
| accent | `#632228` | Oxblood — primary action color |
| accent-hover | `#4D1A1F` | Darker oxblood for pressed |
| accent-subtle | `#E8D8D4` | Light oxblood tint for selection |
| phase-focus | `#632228` | Focus phase ring color |
| phase-short-break | `#5A7D5A` | Short break ring (sage green) |
| phase-long-break | `#5A7A8A` | Long break ring (slate blue) |
| success | same as short-break | Positive indicators |
| danger | same as accent | Destructive actions |
