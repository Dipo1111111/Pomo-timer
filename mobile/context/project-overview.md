# Mobile App — Project Overview

## What
A React Native Pomodoro timer for Android, pixel-identical to the existing web PWA. Same design, same flow, same data model — running natively on the Play Store.

## Why
The web PWA works great, but distribution through the Play Store reaches users who don't browse for productivity tools. A native Android app also gets better OS integration (notifications, background audio, always-on display).

## Who
- **Primary user**: Android users who want a refined focus timer
- **Current user**: The developer, using internal testing
- **Environment**: Android phone, installed from Play Store

## Core Philosophy
Same as the web app: minimalist luxury. The timer is the hero. Everything else is secondary. Clean, confident, precise — just running natively.

## Success Metrics
- **Day 1**: App installs from Play Store internal testing link, opens directly to onboarding then timer, runs a full focus cycle
- **Day 7**: Used daily, stats accumulate, no crashes
